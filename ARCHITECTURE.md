## 阶段一架构（基础功能）

```
Quasar + Electron + Node.js 单体应用
┌───────────────────────────────────────────────────────┐
│  Quasar 前端 (Vue 3 + TypeScript)                    │
│  ├─ 响应式布局（桌面/平板/手机自适应）                 │
│  ├─ 照片网格浏览                                      │
│  ├─ 虚拟相册（按日期/相机/地点/自定义）                │
│  └─ 搜索筛选功能                                      │
├───────────────────────────────────────────────────────┤
│  Express.js API 层                                   │
├───────────────────────────────────────────────────────┤
│  Node.js 业务逻辑                                    │
│  ├─ 文件扫描与监控 (chokidar)                        │
│  ├─ EXIF解析 (exifr)                                │
│  ├─ 目录组织模块                                     │
│  │   ├─ 导入监控目录监听                             │
│  │   ├─ 重复检测 (文件hash)                         │
│  │   └─ 磁盘组织方案执行                             │
│  ├─ 相册管理                                        │
│  ├─ 图像处理 (Sharp)                                │
│  └─ 数据存储 (SQLite)                               │
├───────────────────────────────────────────────────────┤
│  本地文件系统                                        │
│  ├─ 照片源目录（按配置规则组织）                      │
│  ├─ 导入监控目录（自动检测）                          │
│  ├─ 待处理目录（重复照片暂存）                        │
│  └─ 缩略图缓存目录                                   │
└───────────────────────────────────────────────────────┘
```

**特点**：
- 单进程架构，无通信开销
- Quasar框架实现一次开发多端输出
- 三重组织策略：磁盘组织 + 虚拟相册 + 智能搜索
- 远程访问模式：Express监听0.0.0.0

## 阶段二架构（AI增强）

```
Quasar + Electron + Node.js + Python 多进程架构
┌───────────────────────────────────────────────────────┐
│  Quasar 前端                                         │
├───────────────────────────────────────────────────────┤
│  Express.js API 层                                   │
├───────────────────────────────────────────────────────┤
│  Node.js 主进程                                      │
│  ├─ 基础业务逻辑 (同阶段一)                          │
│  └─ AI服务桥接                                       │
│     └─ IPC通信 (ZeroMQ/gRPC)                        │
├───────────────────────────────────────────────────────┤
│  Python AI 服务进程 (长驻)                           │
│  ├─ 人脸识别                                        │
│  ├─ 相似照片检测                                    │
│  └─ 场景分类                                        │
├───────────────────────────────────────────────────────┤
│  共享数据存储                                        │
└───────────────────────────────────────────────────────┘
```

**关键设计**：
1. **长驻Python进程**：应用启动时同时启动Python进程
2. **高效IPC通信**：使用ZeroMQ或gRPC，比HTTP更快
3. **批量处理**：Node.js将多张照片批量发送给Python处理
4. **异步处理**：AI任务在后台异步执行，不阻塞主界面

## 核心数据流

### 照片导入流程

```
用户放入照片到导入监控目录
        ↓
    自动检测新文件 (chokidar)
        ↓
    读取EXIF信息 (exifr)
        ↓
    检测重复 (文件hash对比数据库)
        ↓
    ┌──────────┴──────────┐
    │                     │
无重复                有重复
    │                     │
    ↓                     ↓
按配置规则            移到待处理目录
组织存储到            等待用户决策
照片源目录
    │                     │
    └──────────┬──────────┘
               ↓
       更新数据库索引
               ↓
           UI显示
```

### 磁盘组织方案修改流程

```
用户修改磁盘组织配置
        ↓
    预览：显示将移动X张照片到Y个新位置
        ↓
    用户确认
        ↓
    重命名原照片源目录为"xxx_旧配置"
        ↓
    新建照片源目录
        ↓
    分批整理照片到新目录
        ↓
    完成后删除旧配置目录
        ↓
    更新数据库路径
        ↓
    完成通知
```

### 远程访问流程

```
用户开启远程访问模式
        ↓
    Express监听0.0.0.0:3000
        ↓
    手机浏览器访问 http://台式机IP:3000
        ↓
    加载Quasar PWA界面
        ↓
    与桌面端相同的完整功能体验
```

## 三重组织策略

| 层级 | 描述 | 特点 |
|------|------|------|
| **磁盘组织** | 按配置规则存储文件 | `{year}/{month}/{day}/{filename}` |
| **虚拟相册** | 数据库中按多种维度组织 | 日期/相机/地点/自定义标签 |
| **智能搜索** | 多维度搜索筛选 | 文件名/标签/EXIF信息 |

## 设计原则总结

1. **只读索引，不动原件**：数据库仅建立索引，不移动原始照片（导入时除外）
2. **三重组织策略**：磁盘简单存储 + 虚拟相册灵活组织 + 智能搜索快速定位
3. **原子性操作**：修改组织方案时先备份再执行，确保数据安全
4. **一次开发多端输出**：Quasar实现桌面/移动/Web统一体验
5. **渐进增强**：第一阶段基础功能，第二阶段AI增强
