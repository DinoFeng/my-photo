# 快速开始指南 - 相册功能

**创建日期**: 2026-06-28
**项目**: NAS 照片管理系统

---

## 1. 开发环境

### 1.1 启动开发服务器

```bash
# 后端
cd backend
pnpm dev       # 启动 Express API 服务器 (默认 3000 端口)

# 前端
cd frontend
pnpm dev       # 启动 Vite 开发服务器 (默认 5173 端口)

# 或者在项目根目录使用项目脚本
pnpm dev
```

### 1.2 访问系统

- 前端: http://localhost:5173
- 后端 API: http://localhost:3000/api
- Basic Auth: admin / password（如果仍在使用）

## 2. 首次使用流程

### 2.1 系统初始化

1. 启动服务后，第一次访问前端页面
2. 检测到无用户 → 自动显示初始化向导
3. 创建管理员账号：
   - 输入用户名（如 admin）
   - 输入密码
   - 输入昵称（如 爸爸）
   - 选择头像表情（如 👨）
4. 点击创建 → 自动登录进入系统

### 2.2 创建家庭成员

1. 以管理员身份登录
2. 进入"设置" → "用户管理"
3. 点击"新建用户"
4. 输入：昵称 + 头像表情
5. 保存 → 系统生成邀请码
6. 将邀请码发送给家庭成员

### 2.3 家庭成员登录

1. 成员打开网页 → 登录页
2. 选择"邀请码登录"
3. 输入邀请码
4. ✅ 直接进入系统
5. 浏览器记住登录状态，下次打开自动进入

### 2.4 创建第一个相册

1. 点击导航栏的"相册"
2. 点击"新建相册"
3. 输入相册名称（如"2026年春节"）
4. 可选输入描述
5. 选择可见性（默认：私有）
6. 点击创建 → 进入相册详情

### 2.5 添加照片到相册

方法一：从相册详情页
1. 在相册详情页点击"添加照片"
2. 在弹出的照片选择器中选择照片（支持多选）
3. 点击确认 → 照片添加到相册

方法二：从照片详情
1. 在照片画廊中点击某张照片
2. 在照片详情中点击"添加到相册"
3. 选择目标相册 → 确认

### 2.6 分享相册给朋友

1. 进入相册详情页
2. 点击"分享"按钮
3. 点击"生成分享链接"
4. 复制链接（如 https://nas.local/share/album/aB3xY7_Zq1k）
5. 发送给朋友 → 朋友无需登录即可浏览该相册的照片

### 2.7 撤销分享

1. 进入相册详情页 → 分享管理
2. 看到该相册的所有分享链接
3. 点击某条分享的"删除" → 链接立即失效

## 3. 常用操作速查

### 3.1 相册操作

| 操作 | 位置 | 权限 |
|------|------|------|
| 查看相册列表 | 导航 → 相册 | 已登录用户 |
| 创建相册 | 相册列表 → 新建 | 已登录用户 |
| 编辑相册信息 | 相册详情 → 编辑 | 所有者 |
| 设置相册封面 | 相册详情 → 某张照片 → "设为封面" | 所有者 |
| 删除相册 | 相册详情 → 删除（需二次确认） | 所有者 |
| 查看共享相册 | 相册列表中带"共享"标记 | 已登录用户 |

### 3.2 照片操作

| 操作 | 位置 | 权限 |
|------|------|------|
| 添加到相册 | 照片详情 → "添加到相册"；或相册详情 → "添加照片" | 相册所有者 |
| 从相册移除 | 相册详情 → 照片卡片右上角菜单 → 移除 | 相册所有者 |

### 3.3 用户管理（管理员）

| 操作 | 位置 |
|------|------|
| 查看所有用户 | 设置 → 用户管理 |
| 创建新用户 | 用户管理 → 新建用户 |
| 禁用用户 | 用户列表 → 切换状态开关 |
| 重新生成邀请码 | 用户详情 → "重新生成" |

## 4. 常见问题

### Q1: 忘记管理员密码怎么办？

A: 目前没有密码找回机制。可以在数据库中直接重置（删除 user 表中的管理员用户，重启后重新进入初始化流程）。或者设置环境变量触发密码重置（未来版本）。

### Q2: 删除相册会删除原始照片吗？

A: 不会。删除相册只会删除相册的定义和照片与相册的关联记录，原始照片文件和 media 表中的记录不受影响。

### Q3: 一张照片可以在多个相册中吗？

A: 可以。相册是照片的逻辑分类，不是文件夹。一张照片可以同时被添加到多个相册中。

### Q4: 分享链接安全吗？

A: 分享链接使用长随机字符串（约 22 字符），无法被暴力破解。但分享链接本身是公开的，任何知道链接的人都可以访问，因此：
- 只分享给信任的人
- 不再需要时及时撤销
- 分享链接只开放该相册的只读访问权限，不暴露系统其他信息

### Q5: 如果家庭成员在多个设备上使用怎么办？

A: 邀请码可以在多个设备上使用，都登录为同一用户。每个设备的会话独立管理。

### Q6: 可以修改相册的可见性吗？

A: 可以。在相册详情页点击"编辑"，可以将可见性在"私有"和"所有登录用户可见"之间切换。

## 5. 功能范围说明

### 当前版本包含

- ✅ 多用户系统（管理员 + 家庭成员）
- ✅ 密码登录（管理员）+ 邀请码登录（其他用户）
- ✅ 相册 CRUD（创建、编辑、删除）
- ✅ 照片与相册的关联管理（添加、移除）
- ✅ 相册可见性设置（私有 / 所有登录用户可见）
- ✅ 生成相册分享链接
- ✅ 撤销分享链接
- ✅ 公开分享页面（无需登录，只展示被分享的相册）

- 相册内照片手动排序
- 照片评论、点赞
- 图片编辑/滤镜
- 相册打包下载 ZIP
- 邀请码过期时间
- 多管理员
- 相册分类标签
